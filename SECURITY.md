# Security Policy

## Supported Versions
We support only the latest release of Creator AI Studio.

## Reporting a Vulnerability
Please send an email to [your-email@example.com] with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We aim to respond within 72 hours.

## Disclosure
When a security vulnerability is reported, we will:
1. Confirm receipt within 24 hours
2. Provide an initial assessment within 72 hours
3. Work with reporter to fix and release patch
4. Credit reporter in security advisories (if desired)
